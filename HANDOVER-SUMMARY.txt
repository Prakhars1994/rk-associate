================================================================================
                         BACKEND APIs (READY TO CODE)
================================================================================

AUTHENTICATION ENDPOINTS
  POST /api/auth/register        Register new user
  POST /api/auth/login           Login with email/password
  Function: JWT token generation & verification

TICKET MANAGEMENT ENDPOINTS
  POST /api/tickets              Create support ticket
  GET /api/tickets               List user's tickets
  POST /api/tickets/{id}/comments  Add comment to ticket
  GET /api/tickets/{id}/files    List files in ticket

FILE UPLOAD ENDPOINTS
  POST /api/files/upload         Upload file to ticket
  GET /api/tickets/{id}/files    List shared files
  DELETE /api/files/{id}         Delete file (admin)

PAYMENT ENDPOINTS
  POST /api/payments/create      Create Razorpay order
  POST /api/payments/verify      Verify payment signature
  GET /api/payments/{id}         Get payment details

CERTIFICATE ENDPOINTS
  POST /api/certificates/generate  Generate course certificate
  GET /api/certificates/{code}     Get certificate by verification code
